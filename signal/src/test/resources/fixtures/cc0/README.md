# CC0 real-wheel fixture

`bicycle_spokes_brushed.wav` is a 44.1 kHz mono PCM recording of an item
brushed across bicycle spokes. It is a useful real-world multi-impact/negative
fixture; it is not labelled with individual spoke frequencies or tensions.
